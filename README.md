# CAT CLASH: ULTIMATE ARENA

A chaotic, physics-flavoured **local multiplayer pixel-art cat brawler** for
1–4 players on one machine. Adorable cats, terrible violence: swords, frying
pans, rocket launchers, rubber chickens and giant fish.

Built with **Godot 4.3** (GDScript). Runs on **Linux and Windows**. All art,
the font, sound effects and music are **generated by code at runtime**, so
there are no binary assets to import.

---

## Quick start

1. Install **Godot 4.3** (standard build, not .NET):
   <https://godotengine.org/download/archive/4.3-stable/>
2. Run the game directly:
   ```sh
   godot --path /path/to/CAT-CLASH
   ```
   or open `project.godot` in the Godot editor and press **F5**.

No import step, plugins or extra downloads are required.

### Building a standalone executable

`export_presets.cfg` contains **Linux** and **Windows** presets.

1. Install the Godot 4.3 export templates (Editor → Manage Export Templates).
2. Export:
   ```sh
   godot --headless --path . --export-release "Linux"   build/linux/CatClash.x86_64
   godot --headless --path . --export-release "Windows" build/windows/CatClash.exe
   ```

## Controls (all remappable in Settings → Controls)

| Action            | Keyboard Left | Keyboard Right            | Gamepad          |
|-------------------|---------------|---------------------------|------------------|
| Move / aim        | W A S D       | Arrow keys                | Left stick / D-pad |
| Jump (double jump, wall jump) | Space | Numpad 0 / Enter    | A                |
| Light attack      | F             | Numpad 1 / `.`            | X                |
| Heavy attack (hold to charge) | G | Numpad 2 / `/`            | Y                |
| Pick up / throw (down = drop) | R | Numpad 3 / `;`            | B                |
| Dodge / roll / air dodge | E      | Numpad 5 / `'`            | RB / RT          |
| Block (tap = parry) | Q           | Numpad 4 / L              | LB / LT          |
| Taunt             | T             | Numpad 6 / K              | Select / Back    |
| Pause             | Esc           | Numpad Enter / Backspace  | Start            |

Menus work with either keyboard half, any gamepad or the mouse.

**Moves:** directional attacks (up = launcher, down = sweep or spike in the
air), charged heavies, combos chained from light attacks, dash attacks while
sprinting, wall-clinging and wall-jumps, fast-fall (hold down), and drop
through platforms (down + jump). Press block just before a hit to **parry**
(it stuns melee attackers and reflects projectiles). Press block as you crash
into the floor or a wall to **tech** and recover instantly.

## What's in the game

- **4-player local multiplayer:** two keyboard halves plus up to 8 gamepads,
  hot-plugging, a pause prompt when a controller disconnects (continue as CPU
  or reconnect), and CPU opponents at 4 difficulty levels.
- **13 game modes:** Free-for-All, 2v2 Teams, 1v1 Duel, Stock, Timed, Weapon
  Roulette, King of the Hill, Capture the Fish, Survival (co-op or competitive
  waves), Boss Battle (the two-phase MECHA-MOUSER 9000), Chaos, Training and
  Tournament brackets.
- **12 arenas:** Rooftop Rumble, Sushi Restaurant, Neon Dojo, Pirate Ship,
  Frozen Lake, Volcano Arena, Cat Castle, Arcade Arena, Junkyard, Haunted
  Mansion, Space Station and Garden Dojo. They include moving platforms, ice,
  conveyors, low gravity, and telegraphed hazards (rising lava, trapdoors,
  lasers, a crusher, a cannon, icicles, haunted vases, stove flames and
  updraft vents).
- **40 weapons:**
  - Melee: blades, blunt weapons, spears, fists and a chain whip.
  - Ranged: bows and guns.
  - Special: a boomerang, rockets, a freeze ray, a gravity gun, a lightning staff, a fire wand, a bubble cannon, a black-hole orb and a tiger-transformation potion.
  - Funny: a giant fish, a baguette, a rubber chicken (every fifth hit is a MEGA SQUEAK), a foam sword, a spoon and a fish hammer.
  - Improvised arena props that break after use.
  - Every weapon can be thrown, and strong hits knock weapons out of paws.
- **11 power-ups:** speed, extra jump, shield, magnet, blink, giant, feather
  fall, decoy clone, fire paws, weapon upgrade and a healing fish. They can be
  switched off for competitive play.
- **Cat Creator:**
  - Coat: fur colours, 9 patterns (tabby, spots, tuxedo, calico, Siamese and more), eye colour and shape, ears, tails, whiskers, expressions, body type and idle personalities.
  - Gear: 33 accessories.
  - Style: weapon skins, attack trails, victory poses, entrances, KO effects, nameplates, profile icons and taunts.
  - Saved presets can be renamed, duplicated and deleted.
- **Progression:**
  - Profiles and detailed statistics, 25 achievements and 5 training milestones, daily challenges and per-cat mastery levels.
  - A trophy cabinet and a shop where you spend yarn you earn by playing.
  - Cosmetics never affect gameplay.
- **Accessibility:**
  - Remappable controls, plus stick deadzone and sensitivity settings.
  - Screen shake slider, reduce-flashing option and simplified effects.
  - Colour-blind palette; player and team shapes so nothing relies on colour alone.
  - Large HUD, damage-number toggle, bot difficulty, and adjustable lives, time and rounds.

See [docs/FEATURES_AND_LIMITATIONS.md](docs/FEATURES_AND_LIMITATIONS.md) for
the full list and known limitations.

## Project layout

```
project.godot            engine config (480x270 pixel canvas, autoloads)
export_presets.cfg       Linux + Windows export presets
scenes/main.tscn         single root scene; screens are built in code
scripts/
  main.gd                entry point + developer switches
  autoload/              global services
    settings.gd            persistent settings (user://settings.json)
    pixel_font.gd          runtime 5x7 bitmap font + text helpers
    game_db.gd             data registry + startup validation
    save_data.gd           profiles, stats, presets, unlocks, achievements
    input_hub.gd           multi-device input, bindings, menu events
    audio_hub.gd           synthesized SFX pool + music playback
    router.gd              screen router, session state, toasts
  core/                  shared helpers (palette, sprite factory, music
                         generator, UI kit, menu widget, session builder)
  data/                  data-driven content: weapons, arenas, modes,
                         cosmetics, achievements, pixel-art grids
  gameplay/              fighter, puppet renderer, attacks, AI, items,
                         projectiles, effects, arena, hazards, camera,
                         HUD, pause menu, boss, match controller
  gameplay/modes/        BaseMode + one script per game mode
  ui/                    menu screens
  dev/                   smoke tests, screenshot tour, benchmark
docs/                    asset pipeline, testing checklist, features
```

How to add new content:
- **A weapon:** add an entry to `data/weapon_defs.gd` and a sprite grid to `data/sprite_art.gd`. The moveset is generated from its archetype and stats.
- **An arena:** add an entry to `data/arena_defs.gd` with layout, spawns, hazards and colours.
- **A mode:** add an entry to `data/mode_defs.gd` and a script that extends `BaseMode`.
- **A cosmetic:** add a sprite grid plus a catalogue entry in `data/cosmetic_defs.gd`.

## Developer tools

Pass these switches after `--`:

```sh
# Parse-check every script
godot --headless --path . -- --check

# Automated smoke test: all modes x arenas x 1-4 bots, save round-trip
godot --headless --path . --fixed-fps 60 -- --smoke

# Screenshot tour of every screen and arena (needs a renderer)
godot --path . --fixed-fps 60 --resolution 960x540 -- --shots

# Performance benchmark (4-bot chaos match)
godot --path . -- --bench

# Jump straight into an all-bot match: MODE,ARENA,PLAYERS
godot --path . -- --quick=koth,volcano,4
```
